Repo: korijen klona `logomedo-desk` (macOS: /Users/ms/git/logomedo/logomedo-desk; Windows: gdje je kloniran), grana `main`, javan (github.com/logomedo/logomedo-desk, AGPL), wrap-up pusha `main` i grane `logomedo` u forkovima.

Pročitaj prvo: CLAUDE.md, docs/handoffs/README.md (lanac i pravila), docs/plan.md, docs/decisions.md, docs/forkovi.md, docs/arhitektura.md, TODO.md (F0).

# S1: Windows alati, build originala, lokalni poslužitelji

Polazni commit: (upisuje S0). `./scripts/provjeri.sh`: ne postoji, nastaje u ovoj sesiji. Odluke od **100**.

Računalo: **Windows** (odluka 1), Claude Code u Git Bashu. Ako je sesija pokrenuta na macOS-u, ne radi Windows dio: javi to i stani.

Paket:

1. **Klon i submoduli:** ako repo nije kloniran, `git clone --recursive https://github.com/logomedo/logomedo-desk.git`, pa `powershell -File scripts\postavi.ps1` (uključuje `core.longpaths`). Kratki put (npr. `C:\dev\logomedo-desk`) zbog duljine putanja u vcpkg/cargo.
2. **Alati** prema `docs/forkovi.md` i Windows jobu u `vendor/rustdesk/.github/workflows/flutter-build.yml` (pročitaj samo taj job, grepom): Visual Studio Build Tools s C++, LLVM (verzija iz CI-ja), vcpkg na commitu `9e593bb18ea69cc5095e012465dcd675a822ed0d` i paketi koje CI instalira (libvpx, libyuv, opus, aom…), Rust prema CI-ju, **Flutter 3.24.5** izvan sistemskog (FVM ili zasebni direktorij), `flutter_rust_bridge_codegen` 1.80.1 ako ga build traži. Svaku instalaciju i verziju zapiši u `docs/build-windows.md`.
3. **`scripts/provjeri.sh`** (radi u Git Bashu i na macOS-u): ispis i provjera verzija alata prema `docs/forkovi.md`, `git submodule status` bez neočekivanih pomaka, a kasnije i brzi testovi naših izmjena (za sada samo okvir). Izlaz 0 = zeleno.
4. **Build originala** `vendor/rustdesk` po CI koracima (`python build.py --flutter` ili kako CI radi za Windows x64). Duge korake (vcpkg install, cargo build) pokreni u pozadini, s javljanjem samo na kraju ili kod greške. Izmjeri trajanje svakog koraka (`time`) i veličinu exe-a.
5. **Lokalni poslužitelji na Windowsu:** ako ima Docker Desktop, `docker compose -f server/docker-compose.yml up -d`; inače izvorni `hbbs.exe`/`hbbr.exe` iz izdanja rustdesk-servera i `livekit-server` za Windows (provjeri postoji li; ako ne postoji, LiveKit ostaje na drugom računalu ili u WSL-u i to zapiši). Javni ključ: `server/data/id_ed25519.pub` (gitignored).
6. **(!) Spoj dvije instance:** izgrađeni `rustdesk.exe` postavi na lokalni hbbs (ID server + ključ u postavkama), provjeri registraciju u logu hbbs-a. Drugo računalo (npr. Mac s instaliranim RustDeskom, u istoj mreži) postavi na isti server i spoji se na Windows instancu. Ako korisnik nije tu za klik na drugom računalu, pripremi točne upute i upiši ih na vrh `S2.md`.

Zamke: duge putanje na Windowsu, antivirus koji usporava ili blokira cargo/vcpkg (zapiši ako se dogodi), port 21118 na Macu drži instalirani RustDesk (u compose je 21128).

Gotovo kad: `./scripts/provjeri.sh` vraća 0; `rustdesk.exe` izgrađen (exit 0, put i veličina zapisani); hbbs log pokazuje registraciju ID-a; (!) veza s drugog računala prolazi ili su upute za nju na vrhu `S2.md`; `docs/build-windows.md` ima točne naredbe i izmjerena trajanja. Zatim po lancu, `/wrap-up` sa sadržajem `S2.md`.
